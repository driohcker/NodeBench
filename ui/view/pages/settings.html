⚡ 测试参数

可编辑
initVUs — 测试开始时并发用户数
maxVUs — 测试峰值并发上限
duration — 每个压力阶段的持续时间
waitPeriod — 阶段间等待时间
maxVuIncrement — 未检测到拐点时的提升量
test.outputMode — 数据输出方式
test.testTargets — 默认测试目标序列
🌊 大波动过滤器配置
test.spikeFilter.enabled
spikeFilter.windowSize — 滑动窗口保留点数
spikeFilter.threshold — 差分偏离容忍倍数
spikeFilter.minAbsoluteThreshold — 兜底最小过滤阈值
spikeFilter.minHistory — 开始检测前的最少历史点
spikeFilter.metrics — 需要过滤的指标

🖥️ 服务参数

可编辑
被测服务对外暴露的 HTTP 地址
服务控制接口地址，用于启停管理
Node.js 进程运行模式
cluster 模式下生效，建议设为 CPU 核心数

📈 监控参数

可编辑
monitor.monitorMode — 与测试端输出方式联动

📊 分析参数

可编辑
monitor.algorithm — 默认拐点检测算法
monitor.batchSize — 原始数据点平均窗口
🔴 滑动窗口均值突变检测 配置
每个窗口的数据点数
meanCurr/meanPrev 触发阈值
连续超过阈值次数才判定拐点
开始检测前的最小数据量
🟡 CUSUM 累积和算法 配置
计算基准均值/标准差的初始点数
允许偏移 c 相对于 sigma 的倍数
阈值 H 相对于 sigma 的倍数
开始检测前的最小数据量
🟢 趋势测试（线性回归斜率变化） 配置
每个回归窗口的数据点数
斜率变化触发阈值
连续超过阈值次数才判定拐点
开始检测前的最小数据量

📁 系统路径

可编辑

main.url — 主控制模块监听地址
server.logDir — 被测服务模块日志目录
server.express.logDir — Express 访问日志
monitor.logDir — 监控模块日志目录
analyzer.logDir — 分析模块日志目录
analyzer.strategyDir — 存放分析策略脚本
main.logDir — 主控制器日志目录
